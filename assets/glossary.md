# Glossary

- **AA** — Auto Attendant
- **CQ** — Call Queue
- **CQD** — Call Quality Dashboard
- **DAT** — Technical Architecture / Implementation document (delivery artefact)
- **DEX** — Operational reference / exploitation document
- **Direct Routing (DR)** — Teams Phone connectivity using an SBC between Teams and PSTN
- **Operator Connect (OC)** — Teams Phone connectivity model where operator integrates directly with Microsoft
- **SBC** — Session Border Controller
- **SBCaaS** — SBC as a Service (operator-managed)
- **PBR** — Policy-Based Recording (Teams compliance recording integration)
- **SIPREC** — SIP Recording (RFC 7866), media duplication to a recording server
- **RUN** — Operations phase (post-delivery)
