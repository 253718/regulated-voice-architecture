# How to use this repo (and where proof lives)

This repo is the **entry point**.

## The model

- **Narration** lives here: constraints, decisions, operating model.
- **Proof artefacts** live in a separate technical portfolio repository.
- **Execution** lives privately (tenant-changing runbooks are not public).

## How to read a case study

Each case study ends with a **Proof links** section:

- "what evidence should exist"
- "where to look" (entry points)

## Why the split matters

Regulated environments require:

- traceability
- reviewable artefacts
- clean responsibility boundaries

Keeping narrative and proof separate improves both:

- narrative stays readable
- proof stays factual and audit-ready
