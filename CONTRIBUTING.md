# Contributing

This repository is intentionally small and curated.

## Changes policy

- Prefer **few, high-quality releases** over frequent micro-edits.
- Each release should keep the public surface consistent:
  - anonymized
  - decision-oriented
  - linked to proof artefacts elsewhere

## How to propose changes

1. Open an issue describing the improvement.
2. If adding a new page:
   - reuse the templates and section structure
   - keep language factual and non-marketing
   - include a "Proof links" section pointing to evidence entry points

## Formatting

- Markdown only.
- Use Mermaid diagrams when helpful.
- Keep pages concise: aim for 1–2 screens for principles, 2–4 screens for case studies.
