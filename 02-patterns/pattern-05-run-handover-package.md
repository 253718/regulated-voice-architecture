# Pattern 05 — RUN handover package

## Context

Support teams need predictable artefacts.

## Decision

Standardize a handover package across projects.

## Package contents

- escalation map
- monitoring perimeter
- runbook catalog
- change templates (AA/CQ schedules, message updates)
- recording incident triage guide
- evidence pack baseline

## Evidence expectations

- signed handover checklist
- archived configuration snapshot
